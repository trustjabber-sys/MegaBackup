# MegaBackup

Автоматическое резервное копирование папок сервера в облако [MEGA](https://mega.nz) с уведомлениями в Telegram.

▶️ **Видео по установке:** [https://www.youtube.com/watch?v=VK5d-AUQBFU](https://www.youtube.com/watch?v=VK5d-AUQBFU)

Поддерживаются **Ubuntu** и **Debian**. Архивы создаются в формате `.tar.gz` (без пароля), загружаются в указанную папку MEGA и удаляются по истечении срока хранения.

## Возможности

- Резервное копирование одной или нескольких директорий
- Загрузка архивов в MEGA через неофициальный клиент `mega.py`
- Ежедневный запуск по расписанию (cron)
- Уведомления об успехе и ошибках в Telegram
- Автоматическое удаление устаревших архивов
- Установщик с интерактивной настройкой, удалением и сменой расписания
- Обработка Hashcash-запросов MEGA и повторные попытки при сетевых сбоях

## Требования

- Ubuntu или Debian
- Права root
- Аккаунт MEGA
- Telegram-бот и Chat ID

## Быстрый старт

1. Скачайте оба файла в одну папку:
```bash
git clone https://github.com/trustjabber-sys/MegaBackup.git
```
```bash
cd MegaBackup
```

2. Запустите установщик от root:

```bash
sudo python3 install_MegaBackup.py
```

3. Выберите действие:

```
| Пункт | Действие                     |
| ----- | ---------------------------- |
| **1** | Установить MegaBackup        |
| **2** | Удалить MegaBackup с сервера |
| **3** | Изменить расписание бэкапа   |
```

При установке вас спросят:

- пути к папкам для бэкапа (через запятую, абсолютные);
- корневую папку на MEGA (по умолчанию `MegaBackup`);
- префикс имени архива;
- email и пароль MEGA;
- токен Telegram-бота и Chat ID;
- срок хранения копий в днях (по умолчанию 30);
- время ежедневного запуска (по умолчанию `02:30`).

## Что устанавливается

```
| Путь                            | Назначение                   |
| ------------------------------- | ---------------------------- |
| `/opt/MegaBackup/venv`          | Виртуальное окружение Python |
| `/usr/local/sbin/MegaBackup.py` | Скрипт бэкапа                |
| `/etc/MegaBackup.json`          | Конфигурация (права `600`)   |
| `/etc/cron.d/MegaBackup`        | Расписание cron              |
| `/var/log/MegaBackup.log`       | Лог запусков                 |
```

## Ручной запуск

```bash
/opt/MegaBackup/venv/bin/python /usr/local/sbin/MegaBackup.py
```

Лог пишется в `/var/log/MegaBackup.log`.

## Формат архивов

Имя файла:

```text
{prefix}-{hostname}-{YYYY-MM-DD_HH-MM-SS_UTC}.tar.gz
```

Пример:

```text
MegaBackup-myserver-2026-10-07_14-30-00_UTC.tar.gz
```

Архивы **не шифруются** — это обычные `.tar.gz`. Парольная защита в текущей версии отсутствует.

## Telegram-уведомления

При успехе:

```

При ошибке:

```text

⚠️ Причина: …
```

## Смена расписания

```bash
sudo python3 install_MegaBackup.py
# выбрать пункт 3
```

## Удаление

```bash
sudo python3 install_MegaBackup.py
# выбрать пункт 2 и подтвердить словом DELETE
```

Удаляются только локальные компоненты. Архивы и папка в MEGA **сохраняются**.

## Конфигурация

Файл `/etc/MegaBackup.json` (пример):

```json
{
"backup_paths": ["/home/user/Documents", "/var/www"],
"mega_email": "user@example.com",
"mega_password": "…",
"mega_folder": "MegaBackup",
"archive_prefix": "MegaBackup",
"archive_prefix_history": [],
"telegram_bot_token": "…",
"telegram_chat_id": "…",
"retention_days": 30
}
```

Дополнительные (необязательные) параметры, которые можно добавить вручную:

```
| Параметр                     | По умолчанию         | Описание                               |
| ---------------------------- | -------------------- | -------------------------------------- |
| `upload_retries`             | `3`                  | Число повторных попыток загрузки       |
| `upload_retry_delay_seconds` | `30`                 | Базовая задержка между попытками (сек) |
| `mega_login_retries`         | как `upload_retries` | Повторные попытки входа в MEGA         |
| `mega_timeout_seconds`       | `600`                | Таймаут операций MEGA (сек)            |
```

Переменная окружения `MEGABACKUP_CONFIG` (или `MEGA_BACKUP_CONFIG`) позволяет указать другой путь к конфигу.

## Ограничения и замечания

- Работает только на системах семейства Debian/Ubuntu.
- Требуется root для установки и cron.
- Используется неофициальная библиотека `mega.py` — возможны изменения API MEGA.
- Архивы не защищены паролем.
- При параллельном запуске второй экземпляр пропускается (file lock).
- Установщик не перезаписывает существующую установку — сначала удалите старую версию.
