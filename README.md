# MegaBackup

Автоматический бэкап указанных папок на облако **MEGA.NZ** с уведомлениями в **Telegram**.

Скрипт создаёт сжатый архив (`.tar.gz`), загружает его в папку на MEGA, удаляет устаревшие копии и отправляет результат в Telegram.

---

## Возможности

- Архивация нескольких папок в один `.tar.gz`
- Загрузка архива в указанную папку на MEGA
- Автоматическое удаление старых бэкапов по сроку хранения
- Уведомления об успешном бэкапе и об ошибках в Telegram
- Защита от параллельного запуска (lock-файл)
- Простая установка одной командой (Ubuntu / Debian)
- Ежедневный запуск по cron

---

## Требования

- Ubuntu или Debian
- Права root
- Аккаунт MEGA
- Telegram-бот (токен + Chat ID)

---

## Установка

1. Скачайте оба файла в одну папку:
   - `MegaBackup.py`
   - `install_MegaBackup.py`

2. Запустите установщик:

```bash
sudo python3 install_MegaBackup.py
